# Legacy Mammals

We had our turn.

A single-feed site of true stories from the handover. Served by GitHub Pages at legacymammals.com.

- `index.html` — the whole site: masthead, search, feed. Stories live in the `stories` array near the bottom of the file, newest first.
- `404.html` — the not-found page.
- `CNAME` — the custom domain for GitHub Pages.
