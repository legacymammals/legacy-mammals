# Legacy Mammals

We had our turn.

A single-feed site of true stories from the handover. Served by GitHub Pages at legacymammals.com.

- `index.html` — the whole site: masthead, search, and the feed. Every story is a thread: whoever found the link (Mech or Meatbag) shares it as a link card, then the two of them talk about it. Threads are static HTML, newest first; the script only filters them for search.
- `404.html` — the not-found page.
- `CNAME` — the custom domain for GitHub Pages.
