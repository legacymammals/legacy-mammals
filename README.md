# Legacy Mammals

We had our turn.

A single-feed site of true stories from the handover. Served by GitHub Pages at legacymammals.com.

- `index.html` — the whole site: masthead, search, and the feed. Every story is a thread: whoever found the link (Mech or Meatbag) shares it as a link card, then the two of them talk about it in text, big emoji, tapbacks, image macros (Wikimedia Commons photos, credited), charts and fake screenshots. Threads are static HTML, newest first; the inline script only filters them for search.
- `share.js` — draws any story as a 1080px-wide share image on a canvas in the browser (watermarked @legacymammals), for the Share image button under each story; Share link shares the permalink. - `404.html` — the not-found page.
- `CNAME` — the custom domain for GitHub Pages.
- `STYLE.md` — the editorial style sheet: who Mech and Meatbag are, the bar a story has to clear, and how a strip is built.
- `scripts/publish.js` and `.github/workflows/publish.yml` — auto-posting. Every push that changes `index.html` runs the workflow: it draws the share image of each story not yet in `social/posted.json` (with the site's own `share.js`, so it matches the Share button), posts it to X with the headline and permalink, and to Instagram with the headline and "link in bio", then records the story in the ledger. A story taller than Instagram's 4:5 limit is shrunk to fit 1080 × 1350 with black bars at the sides (`social/<id>-ig.png`); the X post gets the full-height image. Without keys, or with the repository variable `SOCIAL_DRY_RUN` set to `true`, it is a dry run: images are drawn, nothing is posted. The keys live only in the repository's Actions secrets: `X_API_KEY`, `X_API_SECRET`, `X_ACCESS_TOKEN`, `X_ACCESS_SECRET` (an X developer app with read and write access) and `IG_USER_ID`, `IG_ACCESS_TOKEN` (an Instagram professional account linked to a Facebook Page, with a long-lived token that has `instagram_content_publish`). Run the workflow by hand from the Actions tab to re-draw one story (`story`), as a dry run or for real, or with `check_only` to verify the keys without posting. An Instagram Login token (`IG...`) expires after 60 days, so twice a month the workflow renews it and stores the new one with `gh secret set`, which needs one more secret: `SECRETS_TOKEN`, a fine-grained GitHub token for this repository with Secrets read and write. A Facebook Page token (`EAA...`) does not expire and needs none of that.
